\subsection{Теорема Больцано-Вейерштрасса.}

\textbf{Теорема (Больцано-Вейерштрасса).}
Из любой ограниченной последовательности можно выделить сходящуюся подпоследовательность.

\begin{tcolorbox}[title=Доказательство (через вложенные отрезки)]
	Пусть $\{x_n\}$ — ограниченная последовательность.
	Это значит, что все члены последовательности лежат в некотором отрезке $\Delta_0 = [a, b]$.
	
	\begin{enumerate}
		\item \textbf{Построение системы вложенных отрезков:}
		Разделим отрезок $\Delta_0$ пополам на два равных отрезка.
		Так как последовательность $\{x_n\}$ содержит бесконечное число элементов, то по крайней мере в одной из половин находится \textbf{бесконечно много} членов последовательности.
		\begin{itemize}
			\item Обозначим эту половину $\Delta_1 = [a_1, b_1]$.
			\item Длина отрезка: $|\Delta_1| = \frac{b-a}{2}$.
		\end{itemize}
		
		Повторим процесс для $\Delta_1$. Разделим его пополам и выберем ту половину, в которой содержится бесконечно много членов $\{x_n\}$. Обозначим её $\Delta_2 = [a_2, b_2]$.
		
		Продолжая этот процесс, мы построим последовательность отрезков $\Delta_k = [a_k, b_k]$, обладающую свойствами:
		\begin{enumerate}
			\item Вложенность: $\Delta_1 \supset \Delta_2 \supset \dots \supset \Delta_k \supset \dots$
			\item Длина стремится к нулю: $|\Delta_k| = \frac{b-a}{2^k} \xrightarrow{k\to\infty} 0$.
			\item В каждом отрезке $\Delta_k$ содержится бесконечно много членов последовательности $\{x_n\}$.
		\end{enumerate}

		\item \textbf{Применение принципа вложенных отрезков:}
		По принципу вложенных отрезков (Лемме Кантора), существует единственная точка $c$, принадлежащая всем отрезкам сразу:
		$$ c \in \bigcap_{k=1}^{\infty} \Delta_k $$

		\item \textbf{Сходимость границ отрезков:}
		Рассмотрим последовательности концов отрезков $\Delta_k = [a_k, b_k]$:
		\begin{itemize}
			\item $\{a_k\}$ — неубывающая ($a_1 \le a_2 \le \dots$) и ограничена сверху (числом $b$). Значит, $\exists \lim a_k = A$.
			\item $\{b_k\}$ — невозрастающая ($b_1 \ge b_2 \ge \dots$) и ограничена снизу (числом $a$). Значит, $\exists \lim b_k = B$.
		\end{itemize}
		Так как длина отрезка стремится к нулю:
		$$ \lim_{k\to\infty} (b_k - a_k) = \lim_{k\to\infty} \frac{b-a}{2^k} = 0 $$
		Следовательно, пределы совпадают:
		$$ B - A = 0 \implies A = B = c $$
		(Это число $c$ и есть единственная общая точка всех отрезков).

		\item \textbf{Применение теоремы о зажатой последовательности:}
		По построению мы выбирали $x_{n_k}$ так, чтобы он лежал внутри $\Delta_k$. Значит, для любого $k$ выполняется двойное неравенство:
		$$ a_k \le x_{n_k} \le b_k $$
		
		Перейдем к пределу при $k \to \infty$:
		\begin{itemize}
			\item $\lim_{k\to\infty} a_k = c$
			\item $\lim_{k\to\infty} b_k = c$
		\end{itemize}
		
		Тогда по теореме о двух милиционерах (о зажатой последовательности):
		$$ \lim_{k\to\infty} x_{n_k} = c $$
		
		\textbf{Итог:} Подпоследовательность сходится.
	\end{enumerate}
\end{tcolorbox}

\textbf{Следствие.} $\forall \{a_n\} \exists$ подпоследовательность $\{a_{n_k}\}$, которая имеет предел конечный или бесконечный. 

\begin{tcolorbox}[title=Доказательство]
	Рассмотрим два возможных случая для последовательности $\{a_n\}$:
	
	\begin{enumerate}
		\item \textbf{Случай 1: $\{a_n\}$ ограничена.}
			\begin{itemize}
				\item По доказанной выше теореме Больцано-Вейерштрасса, из любой ограниченной последовательности можно выделить сходящуюся подпоследовательность.
				\item Значит, $\exists \{a_{n_k}\}: a_{n_k} \to c$ (где $c$ — конечное число).
			\end{itemize}
			
		\item \textbf{Случай 2: $\{a_n\}$ неограничена.}
			Это значит, что она неограничена сверху ИЛИ неограничена снизу.
			
			\textbf{а) Пусть $\{a_n\}$ неограничена сверху.}
			Это значит $\forall M \in \R, \exists n: a_n > M$. Построим подпоследовательность индуктивно:
			\begin{itemize}
				\item Возьмем $M=1$. Найдем номер $n_1$ такой, что $a_{n_1} > 1$.
				\item Возьмем $M=2$. Так как последовательность неограничена сверху, существует бесконечно много членов больше 2. Найдем номер $n_2 > n_1$, такой что $a_{n_2} > 2$.
				\item ...
				\item На шаге $k$ найдем номер $n_k > n_{k-1}$, такой что $a_{n_k} > k$.
			\end{itemize}
			Получили подпоследовательность $\{a_{n_k}\}$, для которой $\forall k \;\; a_{n_k} > k$.
			По определению предела: $\lim_{k\to\infty} a_{n_k} = +\infty$.
			
			\textbf{б) Пусть $\{a_n\}$ неограничена снизу.}
			Аналогично строим подпоследовательность, выбирая $a_{n_k} < -k$.
			Тогда $\lim_{k\to\infty} a_{n_k} = -\infty$.
	\end{enumerate}
	
	\textbf{Вывод:} В любом случае существует подпоследовательность, имеющая предел (либо число, либо $\pm \infty$).
\end{tcolorbox}
